# Decalin, in 3D

Interactive model of cis- and trans-decalin for CHEM 210 SSG #7C.

Live: https://luxologygg.github.io/decalin-3d/

- Switch between cis and trans.
- Ring flip: cis flips (every axial position becomes equatorial), trans is locked.
- Axial H atoms in red, equatorial in blue, fusion bond and fusion H in orange.
- ax / eq labels on the four ring bonds leaving the shared carbons.
- Look down the fusion bond, or drag to rotate and pinch to zoom.

Geometries are MMFF94-optimized chair-chair conformers built with RDKit. Rendering uses three.js r160 (MIT, see lib/THREE_LICENSE).
